# Bowbert Effects

Reusable effect folders live here when a visual effect is shared or important enough to audit separately from a character body.

- `explosions/kaboomlet/`: Kaboomlet warning radius, blast cloud, explosion ring, and debris burst. The effect is currently runtime procedural.
- `particles/combat-feedback/`: shared combat hit, death, spawn, dodge, damage, wall, spore break, and room-clear feedback. The effect is runtime procedural.

Effect folders mirror the character/projectile folder contract at a smaller scale: `brief.md`, `rig.json`, `tuning.html`, references, exports, and playtest evidence.
